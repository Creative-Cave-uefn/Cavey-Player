# Тексты и альтернативный загрузчик

Тексты из файлов (в том числе ASS и UltraStar со слогами) сохраняют приоритет.
Для нового поиска плеер пробует Musixmatch RichSync через web-протокол
Strvm/musicxmatch-api, перенесённый на Dart без отдельного Python-процесса.
При отсутствии подробных таймингов или ошибке используется LRCLIB и существующее
караоке. Песня выбирается по исполнителю, названию и длительности (±3 с).
RichSync содержит сегменты: они могут быть словами или частями слова, но наличие
точных слогов не гарантируется. Подсветка и перемотка используют существующий рендерер.

Ответы сохраняются локально. Для уже закэшированного текста нажмите обновление
текста, чтобы запустить поиск в новом источнике. Сбой Musixmatch не останавливает плеер.
Неофициальный web-протокол может перестать работать; живой доступ не гарантирован.

## Zotify

1. Установите Zotify и FFmpeg по инструкциям разработчиков Zotify.
2. Запустите Zotify в терминале и выполните вход в Spotify. Плеер не запрашивает пароль.
3. В настройках включите «Использовать Zotify для ссылок Spotify».
4. Если команда не находится через PATH, укажите полный путь к `zotify.exe`.
5. Вставьте ссылку Spotify на трек, альбом или плейлист в обычный загрузчик.

Готовые MP3 загружаются в выбранную папку Google Диска и добавляются в библиотеку.
Вывод Zotify виден в журнале задания. Другие источники используют прежний загрузчик.
Для Zotify не устанавливаются yt-dlp и Deno. FFmpeg должен быть доступен самому Zotify.
Zotify запускается без shell; интерактивный вход внутри плеера не поддерживается.
При ошибке нет незаметного переключения на другой источник аудио.
Порядок коллекции и создание плейлиста Cave Player для Zotify пока не поддерживаются.
Используйте загрузчик для записей, которые вам разрешено скачивать.
