# Тексты и Zotify

Musixmatch использует неофициальный token-based протокол на apic-desktop.musixmatch.com.
Получение токена (token.get), сопоставление записи (matcher.track.get), RichSync
(track.richsync.get); при отсутствии RichSync запрашивается LRC через track.subtitle.get.
Старый web/HMAC-протокол удалён. Описание протокола:
https://github.com/ybenyedder/musixmatch-freeAPI

Токен хранится локально до шести часов, параллельные запросы используют одно получение
токена. При 401 допускается одно обновление; CAPTCHA не обходится, при 429/HTML есть
пауза перед следующим получением токена. Ошибки не содержат токенов или подписанных URL.
Локальные файлы текста имеют приоритет, затем Musixmatch, затем LRCLIB.
Тайминги слов и текст кэшируются. Обновите сохранённый текст вручную для нового поиска.
Кнопка проверки в настройках делает свежий запрос и показывает уровень разметки.
Доступность живого сервиса зависит от сети и ограничений провайдера; unit-тесты
проверяют протокол на искусственных ответах, а не подтверждают доступность сервиса.

Установщик Zotify использует Python 3.11 и отдельное окружение в папке приложения.
Все вызовы pip идут через python.exe -m pip. Источник установки — коммит
08d844fe3e644ae6cd9bea34a3b4982e61129f33 официального репозитория zotify-dev/zotify.
Адрес get.zotify.xyz больше не используется, проверка TLS не отключается.
В Windows CI проверяются создание окружения, обновление pip, установка пакета и --help.
Проверка скачивания через Spotify требует пользовательского входа и отдельно не выполняется.

Нажмите «Установить Zotify», дождитесь успеха и выполните команду входа из журнала
в PowerShell. Для загрузок используйте записи, которые вам разрешено скачивать.
Готовые MP3 попадают в выбранную папку Google Диска и библиотеку плеера.
