# Тексты и загрузчик

Основной онлайн-источник: Better Lyrics (https://docs.betterlyrics.org).
Плеер отправляет /getLyrics четыре поля: название, исполнителя, альбом и целые секунды.
Сохраняет исходный TTML локально, сохраняя пробелы между слогами.
Для ранее сохранённого текста нажмите обновление в панели песни.
Локальные тексты сохраняют приоритет, LRCLIB остаётся резервным источником.
Автоматические запросы к неработающему desktop API Musixmatch отключены.
Старые проверенные тексты из кэша по-прежнему читаются.

Без API-ключа Better Lyrics обслуживает публичный кэш. Cache miss может вернуть 401;
ключи новым пользователям сейчас не выдаются. Эта ситуация показывается отдельно
и не считается доказательством отсутствия текста. Низкая уверенность совпадения,
невалидный TTML, сетевые ошибки и 429 также не подменяются «успешным» текстом.
Ссылку на Better Lyrics можно открыть в настройках. Кнопка проверки делает свежий
запрос и показывает статус кэша и число сегментов.

Zotify устанавливается из закреплённого коммита GitHub, входит через браузер
и скачивает только с сохранённой сессией. При 429 запросы прекращаются.
Retry-After читается даже если маркер оказался после прогресса на той же строке;
код завершения 4 также распознаётся как ограничение. Пауза сохраняется между
запусками. Без Retry-After устанавливается локальная минутная пауза, но срок
ограничения Spotify неизвестен. Повторный вход не требуется.
Обычный загрузчик доступен при отключении Zotify в настройках.
