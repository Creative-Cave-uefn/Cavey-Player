# Adaptive AutoDJ P0

Статус: экспериментальная реализация; Windows-прослушивание и измерение фактического аудиовыхода ещё не выполнены.
Движок media_kit/mpv сохранён. Нет обещания sample-accurate сведения.

**Секционный этап и второй прогон:** см. [INTELLIGENT_DJ_SECOND_PASS.md](INTELLIGENT_DJ_SECOND_PASS.md).
Актуальный анализатор v3 и ограничения: [INTELLIGENT_DJ_STAGE3.md](INTELLIGENT_DJ_STAGE3.md). Старый индекс остаётся совместимым.

## Включение

В настройках переходов включите плавный и умный переход, затем выберите
**Adaptive AutoDJ** в переключателе «Стиль перехода».
Разберите тестовые треки полностью: быстрый/неполный/устаревший анализ не разрешает длинное сведение.
Обычный AutoMix доступен через стиль «Плавный», прежний DJ — через «DJ».

## Поведение

- Планировщик сравнивает до 5 ближайших следующих треков очереди.
- Beam search: горизонт до 3 треков, ширина 6; исполняется только первый переход.
  Характер сета и последние восемь реально запущенных треков влияют на повторы, технику и энергетическую траекторию.
- Оценка совместимости участков отделена от discovery similarity: энергия, спектральный центроид,
  доля баса, границы фраз, риск наложения голосов, допустимая растяжка.
- При наличии секций v2 совместно оцениваются выходы в последних 60 секундах и входы до 24 секунд,
  несколько длин и техник. Для «Свести сейчас» оценивается текущая область. Legacy v1 сохраняет прежние окна 45/12 секунд.
- Техники: beatmatched blend, короткий crossfade, короткий стык на границе фразы,
  атмосферное наложение при малой плотности атак.
- Beat blend использует устойчивые локальные окна v3; legacy-записи используют сетку полного Audio Intelligence. Профиль AutoMix даёт огибающую
  громкости; совпадение с его независимым оценщиком долей больше не требуется. Устойчивость выбранного окна, уверенность темпа и предел растяжения остаются обязательными.
- BPM/Camelot не исключают треки. Неподходящая сетка выбирает переход без beatmatching.
- Кривая вокала V1 — эвристика, не откалиброванная вероятность. Сильное одновременное значение
  повышает осторожность. Независимые метки и модель голоса описаны в актуальной инструкции; низкий score модели не подтверждает отсутствие вокала.
- При слабом анализе сохраняется ближайший трек и обычный AutoMix. Ошибка планировщика также
  не должна мешать воспроизведению. Пара с ручными настройками не переставляется.
- Явно добавленные пользователем треки имеют приоритет, джем не меняется.
- Перед переходом решение фиксируется; перестановка очереди/перемотка инвалидирует его.
- Анализ и подготовка до 5 следующих треков могут скачать их в AudioCache.

Подсказка кнопки «Свести сейчас» показывает выбранную технику и причину fallback.
При ручном нажатии в Adaptive эти сведения также выводятся уведомлением.

В журнал записывается `Adaptive AutoDJ:` и JSON: from/candidates/to/path/technique/reasons,
точки outMs/inMs, длительность и rate. Сохраните строку вместе с SHA сборки для повторения.
Обучения по пользовательским оценкам и нового движка нет. Опциональная модель YAMNet подключается через -WithAudioModels.

## Регрессия «Свести сейчас»

Предыдущая проверка требовала длительность до передачи управления и повторно проверяла
исходную cue-точку после корректирующей перемотки. Длительность потока может прийти позже,
а коррекция фазы может сдвинуть позицию назад. Теперь продвижение транспорта допускает
позднюю длительность; buffering проверяется также опросом, не только событиями позиции.
Повторная проверка старой cue-точки после коррекции удалена. Длительность UI при передаче
берётся из плеера, а если её ещё нет — из метаданных библиотеки/профиля.
Пауза/перемотка отменяют незавершённый переход. Таймаут оставляет исходящую деку основной
и показывает уведомление. Это программное исправление, а не подтверждённый результат прослушивания.

## Воспроизводимый A/B/C набор

Выберите 10–12 своих треков; сохраните их ID и версии файлов. Нет доступа к вашей локальной
музыкальной библиотеке, поэтому конкретные пары и временные метки заполняются на компьютере.
Для каждого сценария используйте одну и ту же пару и одинаковые настройки громкости:

| Сценарий | Входные условия | Что проверить |
|---|---|---|
| 1 | 120 → 122 BPM, инструментальные | устойчивость beat blend |
| 2 | 128 → 92 BPM, разные жанры | наложение без чрезмерной растяжки, cut выключен |
| 3 | два вокальных участка | отсутствие длинного наложения |
| 4 | живые барабаны, нестабильная общая сетка | локальный sync только в устойчивом окне, иначе fallback |
| 5 | эмбиент → ритмичный трек | переход при отсутствии сетки |
| 6 | несовместимая тональность | короткий переход, трек не исключён |
| 7 | большой перепад громкости | нет резкого скачка или перегруза |
| 8 | анализ отсутствует/fast | исходная очередь и AutoMix |
| 9 | cache miss / медленный поток | нет передачи управления неготовой деке |
| 10 | пауза/перемотка во время «Свести сейчас» | управление не заблокировано |
| 11 | повторные «Свести сейчас» | нет зависшей нулевой громкости |
| 12 | пользовательский «следующий» / ручная пара | порядок/настройки сохранены |

A: «Плавный». B: «DJ». C: «Adaptive AutoDJ».
Сначала сравните фиксированные пары через редактор предпрослушивания перехода
(автоматический режим, сохранённые ручные предпочтения для тестовой пары должны отсутствовать).
Затем отдельно сравните подбор: восстановите исходный плейлист перед каждым запуском.
Сравнение качества пары и перестановки сета — разные испытания.

Сохраняйте: SHA, from/to ID, версии файлов, режим, JSON решения, кэш/поток,
оценки timing/smoothness/vocal collision/flow 1–7. Плохой переход повторите не менее трёх раз.
Успешные unit-тесты/сборка не подтверждают качество выходного PCM и отсутствие регрессий Drive.

## Исполнение phrase blend

DJ-огибающая теперь содержит вход 20%, совместное звучание 60%, выход 20%.
В центральном участке обе амплитуды постоянны (equal-power); обмен басами назначается
по плану. Амплитудные коэффициенты преобразуются в кубическую шкалу volume mpv.
Темп/фильтр применяются после открытия входящей деки, пока она беззвучна.
Журнал `DJ execution:` содержит запрошенный/наблюдаемый rate, применение фильтра и момент bass swap.
Ошибка фильтра не записывается как успешное включение. Это не измерение выходного PCM;
поддержку фильтра, перегруз и точность синхронизации нужно проверять прослушиванием/захватом.
Обычный AutoMix не меняется.
