# Загрузчики Cave Player (один активный)

В настройках → Загрузчик музыки выбирается один вариант:

- YouTube / YouTube Music (по умолчанию): название, ссылки YouTube, Spotify, Deezer и Яндекс Музыки. Spotify/Deezer/Яндекс используются только для получения метаданных, аудио ищется на YouTube. SoundCloud не используется даже как запасной источник; прямые ссылки сторонних сайтов отклоняются.
- Soulseek через Sockseek: ввод «Исполнитель - Название» или ссылки каталогов Spotify, Deezer, Яндекс Музыки. Для сети Soulseek необходим отдельный аккаунт; пароль хранится локально в `sockseek.conf`.
- Bandcamp: только прямые ссылки `https://artist.bandcamp.com/track/...` или `/album/...`. Используется extractor yt-dlp и FFmpeg, затем запись MP3 с тегами и загрузка в Google Drive. Для альбомов создаётся папка; частично недоступные треки считаются ошибками, если предварительный список удалось получить. Это аудио доступное для прослушивания, а не купленный lossless-оригинал. Автопоиска по тексту и автовыбора других источников нет.

Старые настройки Sockseek автоматически переносятся в `downloadProvider`. Старые настройки Zotify игнорируются и не записываются обратно. Zotify-процессы, установка, авторизация и CI-проверки удалены. Локальные файлы Zotify, установленные ранее на компьютере пользователя, автоматически не удаляются.

Перед релизом нужно запустить `flutter test` и `flutter analyze`, а затем вручную проверить Windows-сборку и реальные Bandcamp ссылки на свободно распространяемые тестовые треки. Скачивать следует только файлы, на которые есть право.
