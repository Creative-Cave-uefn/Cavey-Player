# Загрузчики Cave Player (один активный)

В настройках → Загрузчик музыки выбирается один вариант:

- YouTube / YouTube Music (по умолчанию): название, ссылки YouTube, Spotify, Deezer и Яндекс Музыки. Spotify/Deezer/Яндекс используются только для получения метаданных, аудио ищется на YouTube. SoundCloud не используется даже как запасной источник; прямые ссылки сторонних сайтов отклоняются.
- Soulseek через Sockseek: ввод «Исполнитель - Название» или ссылки каталогов Spotify, Deezer, Яндекс Музыки. Для сети Soulseek необходим отдельный аккаунт; пароль хранится локально в `sockseek.conf`.
- Bandcamp: только прямые ссылки `https://artist.bandcamp.com/track/...` или `/album/...`. Используется extractor yt-dlp и FFmpeg, затем запись MP3 с тегами и загрузка в Google Drive. Для альбомов создаётся папка; частично недоступные треки считаются ошибками, если предварительный список удалось получить. Это аудио доступное для прослушивания, а не купленный lossless-оригинал. Автопоиска по тексту и автовыбора других источников нет.

Старые настройки Sockseek автоматически переносятся в `downloadProvider`. Старые настройки Zotify игнорируются и не записываются обратно. Zotify-процессы, установка, авторизация и CI-проверки удалены. Локальные файлы Zotify, установленные ранее на компьютере пользователя, автоматически не удаляются.

## Модуль cave-downloader

Код загрузчиков (YouTube, Sockseek, Bandcamp, метаданные Spotify/Deezer/Яндекса, установка yt-dlp, Deno и Sockseek) вынесен из плеера в отдельный публичный репозиторий [`Creative-Cave-uefn/cave-downloader`](https://github.com/Creative-Cave-uefn/cave-downloader). Это консольная программа `cave-downloader.exe`.

- **Установка.** Сразу после запуска Cavey в фоне (а если не вышло — при первом скачивании, «Обновить загрузчик», «Установить Sockseek», «Открыть конфиг Soulseek»; без интернета — снова через 15 минут) берёт из релизов этого репозитория самую новую сборку `v<протокол>.x.y` со своей версией протокола (`kDownloaderProtocol` в `lib/config.dart`), сверяет SHA-256 и кладёт её в папку данных приложения: `cave_player/downloader/`. Сборку без контрольной суммы Cavey не запускает.
- **Обновления.** Раз в сутки (пока Cavey открыт и перед заданием) и по кнопке «Обновить загрузчик». Без связи с GitHub работает уже установленная версия.
- **Обмен.** Плеер слушает `127.0.0.1` на случайном порту и запускает модуль без окна консоли. Модуль присылает журнал и прогресс, а про библиотеку спрашивает плеер: есть ли уже такая песня, в какую подпапку Диска класть альбом, загрузить готовый файл, собрать плейлист. Google Диск и библиотека остаются только в плеере. Код: `lib/core/downloader/`.
- **Программы.** yt-dlp, ffmpeg, Deno, Sockseek и `sockseek.conf` лежат там же, где раньше (`cave_player/tools/`), поэтому у тех, кто уже скачивал, ничего не ставится заново. ffmpeg для караоке и умного перехода плеер по-прежнему ставит сам (`lib/core/tools.dart`).
- **Своя сборка модуля.** Запустите Cavey с переменной окружения `CAVE_DOWNLOADER_EXE=<путь к exe>`, и плеер будет использовать её без скачивания. Другой репозиторий модуля задаётся при сборке: `--dart-define=DOWNLOADER_REPO=владелец/репо`.

Перед релизом нужно запустить `flutter test` и `flutter analyze` здесь и `dart test` в cave-downloader, а затем вручную проверить Windows-сборку и реальные Bandcamp ссылки на свободно распространяемые тестовые треки. Скачивать следует только файлы, на которые есть право.
