## 1. Измерять (делать первым)

- [ ] Кнопка «Отчёт качества»: файл и буфер обмена, названия по умолчанию хешируются
- [ ] Точность темпа и тональности против тегов ваших файлов (с допуском ×2/÷2 и соседних ключей Camelot)

- [ ] Метрики схожести: precision@10 и AUC по парам из альбомов, плейлистов, лайков и быстрых пропусков

- [ ] Список «хабов» (треки, попадающие в чужие соседи слишком часто)

## 2. Схожесть

- [ ] Хрома, повёрнутая к тонике, и признаки, не зависящие от тональности, в режиме «звук»
- [ ] Декорреляция тембра (PCA-отбеливание или Махаланобис)
- [ ] Mutual Proximity / CSLS против хабов, локальное масштабирование ядра
- [ ] Устойчивая нормализация (медиана и MAD), логарифм для герц, логит для долей
- [ ] Громкость отдельной осью, спектральный баланс после нормировки по LUFS
- [ ] Доля вокала, ширина стерео, спектральный наклон, поток спектра в вектор
- [ ] Ритмический дескриптор (автокорреляция огибающей атак, 16–24 значения)
- [ ] Неопределённость отрывков в расстоянии (`d² / (1 + σᵢ² + σⱼ²)`)
- [ ] Сравнение по секциям (лучшее совпадение), квантили признаков по кадрам
- [ ] Обучение весов на ваших данных (логистическая регрессия на признаках пары)
- [ ] Гибрид со статистикой прослушиваний (совместная встречаемость в плейлистах и очереди)
- [ ] Фильтры по темпу и ключу в DJ-режиме жёсткие, а не слагаемые оценки
- [ ] MMR-разнообразие по звуку, кеш top-50 соседей на трек

## 3. Анализ звука

- [ ] Декодировать стерео: M/S, настоящая оценка вокала, ширина
- [ ] Хрома: БПФ побольше для низких частот (или CQT), оценка отстройки, взвешивание гармоник, хрома по басу
- [ ] Сетка долей: динамическое программирование вместо одного BPM, кусочные сетки, допуск 25 мс
- [ ] Тегограммы (DFT × автокорреляция) и приор для октавы темпа, многополосная огибающая атак
- [ ] Структура трека по матрице самоподобия (границы секций, дропы) вместо кратных восьми тактов
- [ ] Краткосрочная LUFS-кривая и true peak
- [ ] Локальная матрица покадровых признаков по долям (около 10 КБ на трек), чтобы обновление анализатора не требовало звука
