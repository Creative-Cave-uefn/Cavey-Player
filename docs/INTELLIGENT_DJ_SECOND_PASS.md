# Intelligent DJ: второй прогон

Актуальные возможности, ограничения, полные команды сборки и A/B:
[INTELLIGENT_DJ_STAGE3.md](INTELLIGENT_DJ_STAGE3.md).

Секционный этап расширен анализатором v3: локальные пульсы/groove,
novelty/recurrence, опциональный голосовой детектор риска, раздельная передача EQ
и acoustic preflight на кэшированных оригиналах. Cut выключен по умолчанию.
Старые записи v1/v2 остаются совместимыми; legacy proxy не разрешает длинный blend.

Внешние вокальные метки по-прежнему можно импортировать с источником `annotation`
или `model:<checkpoint>`, ID и ревизией трека, непересекающимися интервалами
startMs/endMs/probability/confidence. Неполные данные не подтверждают отсутствие голоса.
YAMNet хранится отдельно от таких меток и не выдаётся за откалиброванный SVD.

Для «Свести сейчас» оценивается текущая область. При поздней/неуспешной проверке —
AutoMix. Журнал: текущий файл и одна ротация примерно по 4 МиБ, экспорт объединяет оба.
Он содержит ID/версии треков, но не OAuth, stream URL или аудио.
