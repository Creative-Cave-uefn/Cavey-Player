# Режим Deezer в Cave Player

**Источник:** [kmille/deezer-downloader](https://github.com/kmille/deezer-downloader), версия 2.15.0, MIT. Используется как опциональная локальная Python-библиотека через `assets/deezer_bridge.py`, без отдельного веб-сервера или перехода на YouTube.

## Первичная настройка (Windows)

1. Установите Python 3.10+ и откройте Cave Player → Аккаунты → Загрузчик музыки.
2. Нажмите **Установить deezer-downloader**. Cave Player создаст изолированное окружение `deezer-python` в каталоге инструментов и установит пакет из PyPI.
3. Нажмите **Открыть конфиг Deezer**. В браузере авторизуйтесь в своём Deezer и получите собственный cookie `arl` через DevTools → Application/Storage → Cookies для `deezer.com`. Вставьте значение в `arl = ...`, сохраните файл.
4. Выберите в «Скачать» → **Deezer**. Вставьте `Исполнитель - Название` или прямую ссылку `https://www.deezer.com/track/123`, `/album/123` или `/playlist/123` (допускается `/en/track/...`).
5. Выберите папку библиотеки. Успешно полученные MP3/FLAC попадут в Google Drive через существующий `LibraryController`.

## Если установщик не находит Python

Начиная с исправления `WinProc` запуск `py.exe` и `python.exe` использует поиск через Windows `PATH`, как в терминале. Проверьте в новой сессии PowerShell: `py -3 --version` или `python --version`. Установка требует Python 3.10–3.x. Если Python установлен недавно, перезапустите Cave Player, чтобы процесс получил обновлённый `PATH`.

## Качество

В конфиге `quality = mp3` (по умолчанию) или `quality = flac`. Реальное качество ограничено подпиской Deezer; Free обычно до MP3 128 кбит/с, Premium при соответствующих правах даёт MP3 320 или FLAC. Не выдавайте конвертированный MP3 за lossless.

## Безопасность и ограничения

- `deezer_auth.ini` — секретный локальный файл с токеном сессии, хранится **в открытом тексте**. Не добавляйте его в Git, не делитесь им и не выкладывайте в общую библиотеку.
- Cave Player не запрашивает пароль Deezer и не помещает ARL в аргументы командной строки.
- Поиск по названию строгий: если исполнитель и трек не совпадают, загрузки не будет, даже если найден похожий результат.
- Deezer может менять API, блокировать доступ к конкретным записям или не предоставлять запрошенное качество. Живое скачивание и Windows-сборка требуют проверки на вашем компьютере.
- Программа не предоставляет право сохранять чужой контент. Соблюдайте условия Deezer и права правообладателей.
- Прежний выбранный режим `vk` в сохранённых настройках автоматически переводится на `deezer`. Старые локальные файлы VKpyMusic не удаляются автоматически, но весь VK-код и кнопки из этого архива исключены.
